## Спецификация языка (Language Reference)

### 1. Типы данных и переменные
Язык является строго типизированным. Неявные приведения типов запрещены.

| Тип | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `integer` | 64-битное знаковое целое число | `0` |
| `string` | Строка ASCII в двойных кавычках | `""` |
| `pointer` | Указатель на переменную или элемент массива | `null` |
| `array of <type>` | Массив элементов с автоквантованием (квант = 10) | Массив нулей |

- Идентификаторы без модификатора считаются **константами** и требуют обязательной инициализации.
- Ключевое слово **`mutable`** делает идентификатор изменяемой переменной.

```pascal
// Константы
integer MAX_STEPS := 100;
string MSG := "Searching...";

// Переменные
mutable integer steps := 0;
mutable string status;

// Массивы
mutable array of integer path[100];

// Указатели
mutable pointer integer ptr := &steps;
```

### 2. Операторы и выражения

- **Присваивание:** `:=` (поддерживаются цепочки: `A := B := C;`).
- **Арифметика:** `+`, `-`, `*`, `/`, `%` (целочисленные операции с проверкой деления на ноль).
- **Конкатенация строк:** `+` (`"Hello, " + "World!"`).
- **Арифметика указателей:** `ptr + int`, `ptr - int` (смещение адреса).
- **Сравнения:** `=`, `<`, `>` (возвращают `1` — истина, `0` — ложь).
- **Унарные операторы:**
  - `*<expr>` — разыменование указателя (чтение и запись: `*ptr := 42;`).
  - `&<ident>` — взятие адреса переменной или элемента массива (`&arr[0]`).
  - `?<ident>` — взятие размера (для скаляров всегда `1`, для массива — число элементов).

### 3. Управляющие конструкции

Каждый составной блок инструкций обрамляется ключевыми словами **`start ... finish`**.

#### Ветвление `checkzero ... instead`
Выполняет основное тело, если условие **равно 0**, иначе переходит в блок `instead`:
```pascal
checkzero (can_move)
start
    // Сработает, если can_move == 0 (препятствие)
finish
instead
start
    // Сработает, если can_move != 0
finish
```

#### Цикл `while ... instead` и `break`
Выполняет тело цикла, пока условие **отлично от 0**. Блок `instead` выполняется однократно, если условие было ложно уже на первой итерации:
```pascal
while (steps < 10)
start
    steps := steps + 1;
    checkzero (steps = 5) start finish instead start break; finish
finish
instead
start
    // Сработает только если steps изначально >= 10
finish
```

### 4. Функции и Итераторы

Поддерживаются **рекурсия**, вложенные функции и **лексические замыкания (Closures)**. Параметры передаются по значению.

#### Обычные функции:
```pascal
integer add(integer a, integer b)
start
    return a + b;
finish

start
    mutable integer res := 0;
    res := call add with [5, 10];
finish
```

#### Функции-итераторы:
Итератор получает доступ к текущему элементу массива через слово **`current`** (может быть модифицирующим `mutable`). Индекс последней обработанной позиции доступен через слово **`last`**. Возврат `0` досрочно завершает итерацию.
```pascal
integer processItem(integer item) as mutable iterator for integer
start
    current := current + 1; // Модификация элемента на месте
    return 1;
finish

start
    call processItem for path with [0];
finish
```

### 5. Команды управления роботом

| Команда | Описание | Результат |
| :--- | :--- | :--- |
| `top;` | Перемещение вверх на 1 клетку | `1` — успех, `0` — препятствие (стена) |
| `bottom;` | Перемещение вниз на 1 клетку | `1` — успех, `0` — препятствие (стена) |
| `left;` | Перемещение влево на 1 клетку | `1` — успех, `0` — препятствие (стена) |
| `right;` | Перемещение вправо на 1 клетку | `1` — успех, `0` — препятствие (стена) |
| `timeshift <steps>;` | Возврат на N позиций назад в истории | Сохраняет всю историю перемещений |
| `timeshift "<label>";` | Возврат к контрольной точке по имени | Ошибка, если метка не существует |
| `bind "<label>";` | Привязка строковой метки к текущей позиции | — |

> 🏁 **Выход из лабиринта:** При перемещении на клетку выхода (`E`) программа автоматически завершает выполнение с фиксацией победы.

##  Сборка и запуск

### Требования:
- Компилятор C++ с поддержкой **C++20** (GCC 11+, Clang 13+)
- **CMake** 3.16+
- **Flex** 2.6+
- **Bison** 3.8+

### Запуск:
```bash
./build/maze_game <program.dsl> <maze.txt>
```

#### Формат карты (`maze.txt`):
- `#` — Стена
- `.` — Свободный проход
- `S` — Стартовая позиция робота
- `E` — Выход из лабиринта
